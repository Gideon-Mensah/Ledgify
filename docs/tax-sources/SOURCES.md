# Ghana tax sources checked 12 September 2026

- [GRA VAT reforms](https://gra.gov.gh/domestic-tax/tax-types/vat/): effective 1 January 2026; VAT 15%, NHIL 2.5%, GETFund 2.5%, common base; levies potentially deductible as input tax. Supports Ledgify preset 2026.1, subject to registration and transaction eligibility.
- [GRA notice to VAT-registered taxpayers](https://gra.gov.gh/news/portfolio/notice-to-all-vat-registered-taxpayers/): corroborates effective date, rates, levy input deductibility and ending the flat-rate scheme.
- [GRA E-VAT](https://gra.gov.gh/e-services/e-vat/): authorised integration requires GRA onboarding. No Ledgify certification or connector activation is inferred.
- [GRA WHT guidance](https://gra.gov.gh/portfolio/withholding-tax/): resident/non-resident and payment-type distinctions, payment trigger and certificates. The page alone does not provide a versioned complete current portal code schedule. Catalogue entries remain pending until an authorised user verifies source, effective date, applicability and official code.
- [GRA WHT code schedule](https://gra.gov.gh/wp-content/uploads/2020/09/WHT-TAX-CODES_DESCRIPTION-AND-RATES_2015.pdf): explicitly labelled 2015. Not represented as the current ITAS schedule.
- [GRA VAT withholding](https://gra.gov.gh/domestic-tax/tax-types/vat-withholding/): mentions 7% but also contains older cascading-base/5.5% wording. The 2026 applicability/base transition needs official confirmation before activating a statutory preset.
- [GRA forms](https://gra.gov.gh/forms/): lists DT110/uploadable withholding items, alongside older tax forms. A listing does not verify current CSV columns, codes or portal acceptance.
- [GRA corporate income tax](https://gra.gov.gh/domestic-tax/tax-types/corporate-income-tax/): rates depend on circumstances; no universal automatic CIT computation is introduced.
